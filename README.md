# BrysNews 

Application web d'actualités en temps réel permettant de consulter les dernières nouvelles 
du jour par catégorie.

## Voir le projet en ligne
[brysnews.netlify.app](https://brysnews.netlify.app) 

(https://news-app-mauve-rho.vercel.app/)

## Fonctionnalités
- Affichage d'articles d'actualité en temps réel via une API
- Interface responsive (mobile, tablette, desktop)
- Navigation par catégorie
- Design épuré et lisible

## Technologies utilisées
- HTML5
- CSS3 / SCSS
- JavaScript (Vanilla)
- FontAwesome 6
- Déployé sur Netlify

## Ce que j'ai appris
- Consommation d'une API REST avec fetch()
- Manipulation du DOM en JavaScript
- Gestion du responsive design sans framework
- Déploiement continu via Netlify
